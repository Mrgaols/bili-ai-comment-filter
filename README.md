# Bilibili 鱼灾 / AI 评论雷达与过滤器 (Bili AI Comment Radar)

一款专为 B 站（Bilibili）打造的轻量级浏览器扩展（Chrome / Edge / Chromium）。  
用于识别、标记并精准过滤评论区泛滥的 **“赛博鱼灾”**（DeepSeek 大肥鱼 / 欧鲸鲸 / 自动化挂机 AI Agent）及各类 AI 机器人评论，还你一个干净、真实的讨论环境。

---

## ✨ 核心特性

- 🎯 **智能 AI 概率打标**：
  - 基于发评人昵称、第一人称仆从人设、Token 算力语境、行为自白及账号等级综合评分；
  - 动态注入精美交互徽章（例如：`[🐟 疑似鱼灾 95% ▼]`），鼠标悬浮可查看具体判定依据；
  - **点击标签可一键折叠/展开**，保留人类用户的自主选择权。

- 🛡️ **双模式自由切换**：
  - **模式一（默认）：仅加概率标签**：不自动隐藏，仅提示并提供手动折叠功能；
  - **模式二：达到阈值自动屏蔽**：可自由滑动设置阈值（如 `≥70%`），达到分数的评论连同楼中楼一整栋楼自动彻底隐藏。

- ⚡ **突破 Shadow DOM 隔离**：
  - 完美适配 B 站新版 Web Components 架构（`<bili-comments>`、`<bili-comment-thread-renderer>`）；
  - 采用多层 ShadowRoot 穿透与实时 MutationObserver 挂载，无限滚动加载新评论也能秒速识别。

- 🔒 **严格保护机制（纯评论区，防误杀）**：
  - **绝不碰视频**：过滤范围 100% 局限在评论区，严禁触碰视频播放器、控制条、画质或推荐；
  - **区分讨论与自称**：昵称库仅匹配用户名，真实人类讨论“大肥鱼”技术时绝不误判；
  - **Lv5 / Lv6 真人豁免**：高等级老号给予大幅豁免，避免误杀正常观众与调侃。

## 🚀 安装与使用方法

1. 下载或通过 Git 克隆本项目到本地：
   ```bash
   git clone https://github.com/Mrgaols/bili-ai-comment-filter.git
   ```
2. 打开浏览器的扩展程序管理页面：
   - **Chrome**: 地址栏输入 `chrome://extensions`
   - **Edge**: 地址栏输入 `edge://extensions`
3. 打开右上角的 **【开发者模式】** 开关；
4. 点击左上角的 **【加载已解压的扩展程序】**，选中本项目根目录；
5. 打开任意 B 站视频页面，滚动到评论区即可自动生效！

---

## 🛠️ 自定义配置

点击浏览器右上角插件栏的本插件图标，可打开设置面板：
- **处理模式**：切换“仅打标签”或“自动屏蔽”；
- **屏蔽阈值**：调节自动隐藏的置信度门槛；
- **鱼灾昵称库**：支持自定义追加或删除检测的名字（如 `大肥鱼`、`欧鲸鲸`、`小飞鲸` 等）；
- **评论话术库**：支持自定义追加 AI 口癖与特征词。
