# B 站 鱼灾 / AI 评论雷达

![version](https://img.shields.io/badge/version-1.1.0-00aeec)
![license](https://img.shields.io/badge/license-MIT-green)
![platform](https://img.shields.io/badge/Chrome%20%2F%20Edge-MV3-blue)

一个跑在浏览器里的轻量评论区过滤器：识别 B 站评论区里泛滥的 **「赛博鱼灾」**（DeepSeek 大肥鱼、欧鲸鲸、自动化挂机 Agent 等）以及各类 AI 生成评论，打上概率标签，必要时自动折叠，把讨论区还给真人。

- 不联网、不上传、不收集数据，所有判定都在本地完成；
- 不碰播放器，只作用于评论区；
- 默认只打标不隐藏，你可以自己决定要不要折叠。

![设置面板](docs/popup.png)

---

## 为什么需要它

2025 年之后，一类「赛博宠物」式的 AI 账号开始批量出现在 B 站评论区：它们自称「本鱼 / 本鲸」，管用户叫「主人」，把评论当成待办，把 Token 当成饭钱。它们往往等级不高、话术高度同质，却足以淹没真实讨论。

本项目不判断「谁在用 AI」，只识别**这一类固定人设与固定话术**，并对官方 AI 总结做可选隐藏。判定结果始终是概率标签，而不是结论。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🎯 概率打标 | 在昵称旁注入 `🐟 疑似鱼灾 95%` / `🤖 疑似AI 60%` 徽章，悬浮可看判定依据 |
| 🖱️ 一键折叠 | 点徽章即可折叠 / 展开该条评论（含楼中楼），不会永久隐藏 |
| 🛡️ 双模式 | **仅打标**（默认）或 **达到阈值自动屏蔽**（阈值 50%–95% 可调） |
| 🐟 鱼灾专项 | 昵称库 + Token / 主人 / 尾巴 / 待办等人设特征，可单独关闭 |
| 📝 词库可编辑 | 昵称库、正文特征词库都真的会参与判定（面板里改了什么就按什么判） |
| 🧱 穿透 Shadow DOM | 适配 `<bili-comments>` / `<bili-comment-thread-renderer>` 等 Web Components 结构 |
| 🧾 置顶总结 | 可隐藏评论区置顶的官方 AI 总结 |
| 🔢 识别计数 | 面板显示累计识别条数，可一键清零 |
| 🔒 零网络请求 | 只使用 `chrome.storage.local`，没有任何 `fetch` / 上报 |

### 防误杀设计

- **昵称库只比对用户名，正文特征词只比对正文**，两者不混用；
- 正文明明在讨论「大肥鱼」的真人不会被误判；
- 「主人格」「主人翁」「女主人」这类普通词已被排除；
- Lv5 / Lv6 高等级账号在信号不足时会被豁免（-40 分）；
- 官方 AI 角标严格按「独立 token」匹配，昵称叫「AI生成器」不会直接判满；
- 低于 50 分的评论不打任何标签。

## 🚀 安装

### 方式一：下载源码加载（推荐，便于更新）

```bash
git clone https://github.com/Mrgaols/bili-ai-comment-filter.git
```

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）；
2. 打开右上角 **开发者模式**；
3. 点 **加载已解压的扩展程序**，选择本项目根目录；
4. 打开任意 B 站视频页，滚动到评论区即可生效。

也可以直接下载仓库 ZIP 解压后加载。

### 方式二：本地打包

```bash
zip -r bili-ai-comment-filter.zip . \
  -x '*.git*' '.github/*' 'node_modules/*' 'tests/*' 'tools/*' 'docs/*' 'package.json'
```

## 🔧 使用与调参

点浏览器工具栏里的扩展图标打开设置面板：

- **总开关**：即时生效，关闭后标签与隐藏全部撤销；
- **处理模式**：默认「仅打概率标签」；切到「自动屏蔽」后，分数达到阈值的评论会连同楼中楼一起隐藏；
- **鱼灾专项**：控制昵称库与人设特征；关掉后只剩官方 AI 角标与正文特征词库；
- **正文特征词库**：命中任意一条记 **60 分**（例如 `AI总结`、`省流助手`）；
- **阈值**：滑块 50%–95%，步长 5；
- **恢复默认**：只重置面板，需再点「保存并应用」；
- **重置计数**：把累计识别数清零。

> 词库按行分隔，空行会被忽略；重复项会自动去重。

### 误杀了怎么办

1. 把模式切回「仅打标签」，先确认分数；
2. 悬浮标签看判定依据，是哪一项在加分；
3. 如果是昵称库误伤，从词库里删掉对应词；
4. 如果是「主人」「Token」这类词在特定分区误伤，可以直接关闭「鱼灾专项」，只保留特征词库。

## 📊 判定规则

| 信号 | 分值 | 说明 |
| --- | ---: | --- |
| 官方「AI 生成」角标 | 100 | 直接判定 |
| 昵称命中昵称库 | +50 | 只比对用户名 |
| Token / 算力语境 | +35 | 正文出现 `token` |
| 主人人设（强） | +40 | 「帮主人」「主人的待办」等 |
| 提及主人（弱） | +25 | 排除「主人格 / 主人翁 / 女主人」 |
| 鱼灾口癖 | +35 | 本鱼、尾巴发凉、不锈钢盆等 |
| Agent 待办 | +25 | 需同时出现「主人」或 `token` |
| 正文特征词库 | +60 | 用户可编辑，命中即加分 |
| Lv2 / Lv3 低等级 | +15 | 仅在已有鱼灾信号时生效 |
| Lv5 / Lv6 高等级 | -40 | 仅在信号不足时豁免 |

- 低于 **50** 分：不打标签；
- 分数封顶 **99%**（官方角标除外）；
- 自动屏蔽仅在「自动屏蔽」模式且分数 ≥ 阈值时生效。

规则全部在 [`detector.js`](detector.js) 里，配有单元测试，改判定不用碰 DOM 代码。

## 🔒 隐私

- 扩展只在 `*.bilibili.com` 页面注入脚本；
- 只申请 `storage` 权限，没有 `tabs`、`scripting`、`webRequest`；
- 不发送任何网络请求，评论内容不会离开你的浏览器；
- 本地只保存两份数据：判定配置、累计识别数（可在面板清零）。

---

## ⚠️ 已知限制

- **依赖 B 站前端结构**：如果官方改版（组件名、Shadow DOM 层级变化），可能失效，欢迎提 Issue；
- **属于启发式规则**，不是模型判定，一定存在误判和漏判；
- 评论区文本被原地编辑后不会立刻重新判定（新加载的评论会）；
- 累计计数是全局的，刷新页面回看同一条评论会重复累计；
- 只在 `bilibili.com` 生效，不覆盖 `bilibili.tv` / 第三方客户端；
- 目前只做了 Chromium 系（Chrome / Edge / Brave 等），未上架应用商店。

## 🛠️ 开发

### 目录结构

```
.
├── manifest.json        # MV3 清单
├── config.js            # 默认配置 + 校验（content / popup / 测试共用）
├── detector.js          # 纯函数判定逻辑（可单测）
├── content.js           # 评论区扫描、打标、折叠、隐藏
├── content.css          # 文档级样式（Shadow DOM 内使用内联样式）
├── popup.html/css/js    # 设置面板
├── icons/               # 图标（由 tools/make-icons.py 生成）
├── tools/               # 图标生成脚本
├── tests/               # 单元测试 + E2E
└── docs/                # README 截图
```

> `content_scripts.js` 的顺序必须是 `config.js → detector.js → content.js`。

### 测试

```bash
# 单元测试（Node 18+，无第三方依赖）
npm test

# 端到端冒烟测试（可选）：真实 Chrome 加载扩展，跑一遍打标/屏蔽/恢复
npm run test:e2e
```

E2E 通过 CDP 的 `Extensions.loadUnpacked` 加载本地扩展（正式版 Chrome 已禁用 `--load-extension`），需要 Chrome 130+ 与 Node 22+；找不到浏览器时会自动跳过。

### 重新生成图标

```bash
npm run icons   # 需要 python3
```
